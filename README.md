# StudyFlow — Student Planner

A colourful, responsive student productivity dashboard made with **HTML, CSS and vanilla JavaScript**.

## Features
- Add, complete and delete tasks
- Categorize tasks and set priorities
- Progress tracker and task counters
- Task search by title, category, or priority\n- Task filters: all, to do, completed
- Focus timer with 25-minute focus, 5-minute short break and 15-minute long break modes
- Saves tasks and completed focus sessions in browser local storage
- Responsive design for laptop and mobile

## Run it
1. Extract `StudyFlow_Project.zip`.
2. Open the extracted folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.
4. No installation or build step is required.

## Files
- `index.html` — page structure
- `style.css` — layout, colours and responsive styling
- `script.js` — task management, local storage and timer logic
